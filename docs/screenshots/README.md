# CivicQuest Screenshots

This directory stores visual assets and screenshots used in the project documentation and root `README.md`.

## Recommended Screenshots to Add

Please capture and save the following screenshots with matching filenames:

| Filename | Description | Recommended Dimensions / View |
| :--- | :--- | :--- |
| `home.png` | Citizen Landing / Welcome screen | Desktop or mobile hero view |
| `login.png` | Citizen Authentication (Email OTP verification modal) | Desktop or mobile modal view |
| `works.png` | Works Browser (MPLADS projects feed, search, and filter) | Desktop feed view |
| `leaderboard.png` | Citizen Leaderboard (Top citizen contributors ranked by XP) | Desktop view |
| `profile.png` | User Profile (XP total, submission history, complaint tracking) | Desktop view |
| `complaint.png` | Civic Complaint modal / upload form with camera preview | Mobile or desktop modal view |
| `auditor-dashboard.png` | Auditor Review Portal (Pending submissions, review controls, photo preview) | Desktop view |
| `admin-dashboard.png` | Admin Operations Center (Auditor management, review logs, system metrics) | Desktop view |

> **Tip**: For best presentation on GitHub, capture screenshots in 16:9 or crisp high-DPI resolution (PNG format, optimized using TinyPNG or similar tool).
